# Levid Lima

**`Software Engineer | Full Stack Developer | Tech Lead`**

Hi there! I’m Levid, a Software Engineer passionate about building scalable and high-impact systems. With solid experience in software architecture, I currently work as a Tech Lead, guiding squads in the development and migration of complex, high-traffic platforms.

Besides end-to-end development (Web and Mobile), I have a strong background in Quality Engineering (QA) with test automation and the integration of predictive models using Artificial Intelligence.
